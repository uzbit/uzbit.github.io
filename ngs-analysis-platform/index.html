One hosted platform for your NGS pipelines

Upload your FASTQ, pick an analysis, and download results — no tools to install and no infrastructure to run. The platform bundles read QC and trimming, amplicon diversity, RNA-seq expression, and de novo assembly, and the analyses chain together into pipelines — each one can take the previous job's output as its input. A native C++ engine keeps large runs fast, and cloud workers scale up on demand. Works with Oxford Nanopore, Illumina, and PacBio data.

Analyses built in

Demultiplexing

Sort pooled reads into per-sample bins by barcode, with fuzzy matching modeled on Oxford Nanopore's dorado — including double-ended native barcode kits — plus quality filtering and barcode QC plots.

Clustering

Collapse near-identical sequences into representative centroids with minimizer-accelerated greedy clustering. Dedupe a reference database at strain level, or squeeze redundant nanopore reads before analysis while preserving true abundance.

Diversity Analysis

Map reads to your reference with BLAST+ and an edlib verification step, then compute per-sample Richness, Shannon, Simpson, and Pielou's evenness, with cluster abundance tables ready to drop into a figure.

Differential Expression

Quantify RNA-seq gene expression and call up- and down-regulated genes between two groups with DESeq2 — with volcano plots, MA plots, PCA, and clustered sample heatmaps alongside the full ranked gene table.

Gene Set Enrichment

Turn a ranked gene list into the biological pathways behind it. GSEA reports enrichment scores, significance, and the leading-edge genes, with running-score and dot plots for the top gene sets.

De novo Assembly

Reconstruct genomes and amplicons with no reference using SPAdes — get contigs, N50, GC content, and an assembly graph, including a dedicated mode for polyclonal amplicon libraries such as antibody repertoires.

Built to handle real sequencing runs

Fast by design

The heavy lifting is native C++ — edlib alignment, BLAST+, and minimizer sketching, parallelized with OpenMP. An in-house candidate index narrows each search to a tiny slice of the reference, so the alignment that follows runs an order of magnitude faster with identical results.

Scales on demand

A cloud worker pool wakes up when jobs are queued and shuts itself down when idle, so a big run gets a big machine — without paying for hardware that sits idle between experiments.

Nothing to install

Upload compressed FASTQ in the browser, watch jobs run live with progress and queue position, and download ready-to-use result archives. Organize everything into projects and reuse pinned reference files across them.

Three steps from data to answer

1. Upload

Bring your compressed FASTQ reads and any reference or barcode files, grouped into a project. Pin the files you reuse across experiments.

2. Choose an analysis

Pick a job type, select your inputs — or a previous job's output — and tune the parameters, which start from sensible defaults.

3. Download results

Review metrics and plots in the browser as the job runs, then download a complete, reproducible archive when it finishes.

Results you can publish

Every job produces a downloadable archive: structured metrics, human-readable summaries, and figures — diversity indices and abundance tables, volcano plots and expression heatmaps, enrichment plots, QC reports, assembly stats — alongside the exact parameters used, so every run is reproducible.

Who it's for

Molecular biology and synthetic biology labs that would rather run analyses than maintain them: amplicon and 16S community profiling, nanopore sequencing QC, antibody and variant-library characterization, directed-evolution screens, and RNA-seq transcriptomics.
